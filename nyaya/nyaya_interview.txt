Chalanges faced during building Project

1. Forgot Password Implementation (Learning Nodemailer)

Challenge: I needed to implement a "forgot password" feature where users could reset their password through email verification. Initially, I had limited knowledge of sending emails from the backend.

Solution: I learned how to use Nodemailer to send verification codes via email. Additionally, I made sure that once the code was used to reset the password, it became invalid to prevent misuse. This required careful token management and security practices.

2. Handling Slow Data Fetching (Implemented Pagination)

Challenge: As the list of lawyers grew, fetching and displaying all data at once led to slow load times and performance issues.

Solution: I implemented pagination to only load a subset of data at a time. This not only reduced the load on the server but also provided a smoother experience for users by loading data in smaller chunks as they scroll or navigate through the app.

3. Authentication and Security (JWT, Refresh Tokens, bcryptjs)

Challenge: Ensuring secure authentication was another major challenge. I had to safeguard user data and sessions, prevent unauthorized access, and make sure sessions didn't expire too quickly.

Solution: I implemented JWT (JSON Web Tokens) for authentication, along with refresh tokens for long-lived sessions. For password protection, I used bcryptjs to securely hash passwords. This approach ensured that user sessions were both secure and efficient without compromising user experience.
